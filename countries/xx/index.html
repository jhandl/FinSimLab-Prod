Demo Country Model Note

The free public ruleset used for examples, tests, and non-country-specific scenarios.

Demo Country is the public baseline ruleset. It exists so the simulator can demonstrate income, pension, investment, and property flows without implying that a real jurisdiction is selected.

Use it when a scenario is about simulator behavior rather than local legal detail. For the generation path behind this page, see the model transparency note.
